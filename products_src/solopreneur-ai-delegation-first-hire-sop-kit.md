# The Solopreneur's AI Delegation & First-Hire SOP Kit

Stop being the bottleneck. This kit shows a one-person business exactly what to hand off, how to write a clean SOP in 20 minutes, and how to bring on a first helper without chaos. Copy the prompts, fill the tables, delegate this week.

## 1. The Delegate / Keep / Delete Filter

| Test | If YES | If NO |
|---|---|---|
| Done it 3+ times and can describe the steps? | Delegate (write an SOP) | Keep - not repeatable yet |
| Directly creates revenue or client results? | Keep until stable, then delegate | Delegate first |
| Needs your taste or final judgment? | Keep | Delegate |
| Low-value but necessary (invoicing, scheduling, files)? | Delegate first | Keep |
| Would a mistake cost more than 1 hour to fix? | Keep + checklist | Delegate |

Rule: delegate the thing you did twice, not the thing you are doing right now.

## 3. The 4-Line SOP Template

Keep every SOP under one page. Copy this skeleton:

- **Trigger:** When exactly it starts (event + time).
- **Steps:** Numbered, one action per line. Never write "handle it".
- **Tools:** Exact app, link, folder and template, named.
- **Done looks like:** The verifiable output (file saved, email sent, row updated).

## 4. Copy-Paste AI Prompts

1. "Turn this Loom transcript into an SOP with exactly four sections: Trigger, Steps, Tools, Done looks like. One action per numbered step, no fluff. Transcript: [PASTE]"
2. "Rewrite this SOP so a brand-new VA with zero context can follow it. Flag every ambiguous word and replace it with a specific instruction. SOP: [PASTE]"
3. "Create a 12-point QA checklist to verify this SOP was done correctly. Each item checkable in under 30 seconds. SOP: [PASTE]"
4. "List every decision in this workflow that needs my judgment. For each, write a rule a VA can apply without asking me. Workflow: [PASTE]"
5. "My 5 recurring weekly tasks: [LIST]. Rank by (time saved x ease of handoff). Table with rank, why, and the first SOP to write."
6. "Write a 3-line handoff message for this SOP: what it is, when it happens, where the checklist lives. Warm, plain English."
7. "Draft a 10-minute say-aloud training script for a first hire on this SOP. Include two common mistakes and fixes. SOP: [PASTE]"

## 5. First-Hire Interview Questions That Predict

| Question | Green flag |
|---|---|
| "Tell me about a process you inherited and improved." | Names the exact change + result |
| "What do you do when instructions are unclear?" | Asks one sharp question, then acts |
| "How would you name these 5 files?" | Consistent, logical convention |
| "How do you track work you finish?" | Uses a system, not memory |
| "What would you do in your first idle hour?" | Finds the checklist / next task |

## 6. 14-Day Rollout

| Day | Action |
|---|---|
| 1-2 | Time-audit: log every task |
| 3 | Apply the filter; pick ONE task |
| 4-5 | Record a Loom; write SOP #1 |
| 6 | Run it yourself once; fix gaps |
| 7 | Hand SOP #1 to your helper |
| 8-10 | Write SOPs #2 and #3 |
| 11 | Put all tools and links in one doc |
| 12-13 | Shadow week: review output daily |
| 14 | Decide: keep, rewrite, or replace |

## 7. Three Rules That Prevent Chaos

1. If the SOP is not written, it is not delegated.
2. Never delegate a task you have not done at least twice.
3. Review the output, not the process - unless the client complains.
