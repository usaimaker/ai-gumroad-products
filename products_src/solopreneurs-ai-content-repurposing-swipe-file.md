# The Solopreneur's AI Content Repurposing Swipe File

Stop creating from scratch. Publish ONE core piece a week, then spin it into 12+ assets with these copy-paste prompts. Built for solo founders with no team and no time.

## The 1-to-12 Engine
| Stage | Input | Output |
|---|---|---|
| 1. Source | 1 long-form post / notes | Carousel, thread, email, video, pin |
| 2. Atomize | Each asset above | 3 short posts each |
| 3. Recycle | Top performer | Refresh + repost in 30 days |

## 18 Copy-Paste Prompts
| # | Use for | Prompt |
|---|---|---|
| 1 | Blog to Carousel | Turn the following post into a 10-slide LinkedIn carousel. Slide 1 = hook, last = CTA. Keep each slide under 220 chars. |
| 2 | Post to Thread | Rewrite this article as a 7-tweet thread. Lead with the strongest stat. One idea per tweet. |
| 3 | To Newsletter | Summarize this into a 150-word email with a subject line under 40 chars and one clear takeaway. |
| 4 | To Reel Script | Write a 45-second talking-head script from this point. Hook in 3 sec, 3 beats, strong close. |
| 5 | To Pinterest Pin | Create 5 vertical pin titles + descriptions targeting beginners in [niche]. Include 2 hashtags each. |
| 6 | Hook Variants | Give me 10 scroll-stopping hooks for this topic, one line each, no cliches. |
| 7 | Quote Cards | Extract 8 quotable lines from this text for image cards. |
| 8 | FAQ From Post | List 6 FAQs a beginner would ask after reading this, with short answers. |
| 9 | YouTube Title | Generate 12 YouTube titles (under 60 chars) from this angle, curiosity-led. |
| 10 | Repurpose Win | Identify the 3 most reusable ideas here and how to format each for Instagram. |
| 11 | Email Subject | Write 15 subject lines for this content, mix curiosity and benefit, avoid spam words. |
| 12 | Carousel Hook | Rewrite slide 1 of this carousel to double save-rate. Make it a bold promise. |
| 13 | Mini Guide | Turn this into a 5-step PDF checklist a reader finishes in 10 minutes. |
| 14 | Cold DM | Draft a non-salesy DM referencing this insight, under 90 words, soft CTA. |
| 15 | Testimonial Ask | Write a 3-line message requesting a testimonial based on this result. |
| 16 | Ad Caption | Create 5 Facebook ad captions from this offer, pain-first, one CTA. |
| 17 | Podcast Pitch | Summarize this into a 60-sec podcast intro pitch with 3 talking points. |
| 18 | Monthly Recap | Compile my top 4 posts this month into a recap post with a lessons line. |
