# The Solopreneur's AI Scroll-Stopping Hook Swipe File

A hook decides whether anyone reads the rest. This file gives you 32 fill-in openings for short video, carousels, captions, DMs and email - plus an AI prompt engine to make unlimited more. Copy, swap the brackets, post.

## The 2-Second Hook Formula
| Part | Job | Fill-in template |
|---|---|---|
| Trigger | Call out one person | "If you're a [role] who [pain]..." |
| Tension | Expose the cost | "...you're losing [time/money] to [problem]." |
| Payoff | Promise one specific win | "Here's how to [result] in [time]." |
| Proof | Earn trust in five words | "Did it for [niche], [number]." |
| CTA | Direct the next move | "Save this / comment [word]." |

Minimum viable hook = Trigger + Tension + Payoff. Add Proof or CTA only when the format allows space. Never use all five in one line.

## 5-Step Hook Test (do this weekly)
1. Write 5 hooks for one post. Never publish the first one - it is usually the most generic.
2. Post two versions to the same platform 48 hours apart; keep body copy identical.
3. Track only first-3-second retention (video) or first-line click-through (text) for 24 hours.
4. Keep the winner, rewrite the loser with a different Trigger, and test again next week.
5. Save every winner into this swipe file. After 8 weeks you have a personal hook library that beats any template.

## Pre-Post Checklist
- [ ] Names one specific person, not everyone
- [ ] First 8 words contain the pain or the payoff
- [ ] Contains a number, time frame or concrete object
- [ ] No banned filler: "Hey guys", "Just wanted to", "In this video"
- [ ] Sounds like speech, not an ad
- [ ] Promises one thing only
- [ ] Matches the platform it runs on
- [ ] Has a clear next action
