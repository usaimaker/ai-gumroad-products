# The Solopreneur's AI Landing Page Copy Kit

Stop staring at a blank page. This kit hands you the exact sections, fill-in templates, and copy-paste AI prompts to write a landing page that actually converts - in one sitting, no copywriter required.

## 1. The 6-Part Landing Page Skeleton

Every high-converting page follows the same six blocks. Fill each one from the template.

| # | Section | Its only job | Fill-in template |
|---|---------|--------------|------------------|
| 1 | Hero headline | Name the outcome + who it is for | Get [outcome] without [pain] - even if [objection]. |
| 2 | Sub-headline | Add speed or proof | Join [number] [audience] who [result] in [timeframe]. |
| 3 | Benefit bullets | 3-5 outcomes, not features | You will walk away with [X], [Y], [Z]. |
| 4 | Social proof | Build trust instantly | [Name], [role]: [one-line result quote]. |
| 5 | Objection buster | Kill the number 1 hesitation | Worried about [fear]? [reassurance]. |
| 6 | CTA + risk reversal | One clear next step | Get [product] free. [guarantee]. Button: [verb] my [outcome] |

## 2. 14 Copy-Paste AI Prompts

Run these through any LLM. Swap the brackets for your product.

1. Write 10 hero headlines for a landing page selling [product] to [audience]. Outcome: [outcome]. Tone: confident, plain English, under 12 words.
2. Turn this feature into a customer outcome: [feature]. Give 3 short versions.
3. Write a sub-headline that adds proof to this hero: [hero]. Include a number.
4. List 5 benefit bullets for [product]. Each starts with a verb and ends in a result.
5. Write a one-sentence customer quote that proves [result]. Make it specific, not generic.
6. What is the number 1 objection a [audience] buyer has about [product]? Give me a reassurance sentence for each of the top 3.
7. Rewrite my CTA button text [current] into 8 click-worthy versions that name the outcome.
8. Turn my landing page into a 30-second elevator pitch a total beginner would understand.
9. Find the weak word in this sentence and give 3 stronger replacements: [sentence].
10. Write a 5-line FAQ that answers the doubts that stop [audience] from buying [product].
11. Give me 3 risk-reversal lines (guarantee / no-risk) for [product] that sound honest.
12. Score this headline [headline] 1-10 for clarity and desire. Tell me exactly why and how to fix it.
13. Write a P.S. for my page that restates the offer and adds light urgency without being sleazy.
14. Act as a skeptical buyer and poke 5 holes in this page: [paste page]. Then fix each.

## 4. Objection Buster Table

| Buyer worry | Reassurance template |
|-------------|----------------------|
| Too expensive | Priced less than [cheap alternative] that does half the work. |
| No time | Built to finish in [time]; do it in one sitting. |
| Will it work for me | Used by [audience] with [specific situation]. |
| I am not techy | No code, no setup - copy, paste, done. |
| Risk of waste | [guarantee]; try it, keep it only if it helps. |

## 5. 5-Point Critique Checklist

- [ ] Hero states one clear outcome for one clear audience?
- [ ] Every bullet is a result, not a feature?
- [ ] One proof element above the fold?
- [ ] Single CTA repeated, no competing links?
- [ ] One objection answered before the button?

## 6. 20-Minute Build Sprint

1. (3 min) Paste the skeleton table into your editor.
2. (5 min) Run prompts 1-4 to draft hero, sub, bullets, proof.
3. (4 min) Run prompt 6 plus the objection table for the buster.
4. (4 min) Run prompt 7 for the CTA, add your guarantee.
5. (4 min) Run the critique checklist; fix anything unchecked.
