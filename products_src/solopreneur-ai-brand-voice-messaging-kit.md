## 2. The 5-Element Voice Spec
| Element | Define it | Example |
| --- | --- | --- |
| Tone | Friendly but expert | "Here is the fix." not "Kindly consider." |
| Format | How we structure | Short paragraphs, one idea each |
| Vocabulary | Allowed vs banned | Use "you", ban "leverage" |
| Point of view | We / you / I | Mostly "you" |
| Signature | A recognizable habit | Opens with a question |

## 3. Ten Copy-Paste AI Prompts
| Goal | Prompt |
| --- | --- |
| Draft in-voice | "Write a [post] in the voice of this brand spec: [paste §1+§2]. Topic: [X]. 120 words, no buzzwords." |
| Fix off-brand | "Rewrite this draft to match our voice spec. Keep meaning, cut corporate phrases: [paste]." |
| Hook | "Give 5 opening hooks for [topic] in our tone (curious, direct, no hype)." |
| Email | "Write a 90-word welcome email using our voice spec. One CTA." |
| LinkedIn | "LinkedIn post, conversational, one story, no emoji spam: [topic]." |
| X thread | "7-tweet thread on [topic], punchy, one takeaway per tweet." |
| Instagram | "3 IG captions, casual, end with a question." |
| Blog | "Outline a 600-word blog post in our voice. Headings only." |
| Reply | "Reply to this comment in our tone, helpful not defensive: [comment]." |
| Audit | "Score this text 1-10 for brand fit vs our spec and list fixes: [text]." |

## 4. Channel Voice Cheat Sheet
| Channel | Tone | One rule |
| --- | --- | --- |
| Email | Warm, direct | One ask per email |
| LinkedIn | Pro, story-led | Lead with insight not pitch |
| X | Sharp, opinionated | Max 280, no threads-as-ads |
| Instagram | Casual, visual | Caption ends in a question |
| Blog | Helpful, thorough | Skimmable headings |

## 5. Seven-Day "Lock Your Voice" Sprint
- Day 1: Fill §1 and §2.
- Day 2: Write 3 example posts that nail it.
- Day 3: Paste spec into ChatGPT or Claude custom instructions.
- Day 4: Run 3 prompts from §3, refine spec.
- Day 5: Build a 10-line banned-words list.
- Day 6: Audit last month's content vs the checklist.
- Day 7: Save spec as a reusable file; train your VA or agent.

## 6. Before-You-Publish Checklist
- [ ] Matches §1 adjectives?
- [ ] No banned words?
- [ ] One clear point of view?
- [ ] Reads aloud like you?
- [ ] Single CTA?
